# Minecraft 字體渲染原理與解法

適用Java版1.13 \~ 26.x。

ttf文字是先轉成貼圖再縮放顯示，所以模糊、偏移、缺字等問題多半出在 `size`、`oversample` 與字形圖集；原版只能靠修改 `default.json` 緩解，要根治需要 Modern UI 這類文字引擎模組。

## 一、渲染原理

原版把每個ttf字元先轉成像素貼圖、放進共用的字形圖集，畫面上的文字只是這些貼圖縮放後的結果。

### 四個參數的作用

| 參數           | 作用          | 調高或加大時            |
| ------------ | ----------- | ----------------- |
| `size`       | 字形的繪製大小     | 字變大，圖集貼圖變大        |
| `oversample` | 轉成像素時的解析度倍率 | 縮小後更平滑，但圖集更大、載入更慢 |
| `shift`      | 字形的水平與垂直位移  | 用來對齊原版基準線         |

### 原版沒有的功能

原版沒有字距、hinting、連字的設定，字寬直接取自字體本身。這些限制是下一章多數問題的根源。

## 二、渲染問題

以下問題只針對ttf(或otf)，「可否在原版解決」指只改資源包檔案能否改善。

| 問題                     | 成因                                      | 原版可解決                        |
| ---------------------- | --------------------------------------- | ---------------------------- |
| 文字模糊、邊緣發灰              | 字形帶灰階抗鋸齒；`oversample` 與字體的 em 大小不匹配時更明顯 | 部分可改善                        |
| 縮放 GUI 後清晰度不穩          | 字形圖集解析度在載入時固定，GUI 縮放改變時只能重新取樣           | 部分可改善                        |
| 大小或上下位置與原版不合           | 不同字體的字形比例與基準線不同                         | 可以（`size`、`shift`）           |
| 字距、字寬不理想               | 沒有字距參數，字寬由字體決定                          | 否，只能換字體                      |
| 缺字變方塊或回落成別的字體          | 字體不含該字元，由後面的提供者補上                       | 可以（調整提供者順序、補字體）              |
| 複雜文字顯示錯誤（阿拉伯文、泰文、天城文等） | 字元無法正確連接或組合                             | 否                            |
| 粗體、斜體看起來假              | 原版是合成粗斜體，不會使用字體內的粗體與斜體字形                | 否                            |
| 陰影造成重影                 | 陰影固定繪製，字形越粗越明顯                          | 否，只能選較細字重                    |
| 載入慢、吃記憶體               | 字數多的字體（如中日韓）加高 `oversample`，圖集很大        | 可以（降低 `oversample`、用 `skip`） |
| 世界內文字（告示牌、名牌）遠看失真      | 位圖圖集縮小後沒有距離場等補償                         | 否                            |

> 注意：原版版本不同，細節可能有差異，上表依目前已知行為整理，請以實際畫面為準。

## 三、原版解法

原版能做的只有調整 `assets/minecraft/font/default.json`，一次只改一項，改完按 F3 + T 重新載入，並用不同GUI縮放檢查。

| 症狀         | 調整方向                                        |
| ---------- | ------------------------------------------- |
| 模糊、發灰      | 提高 `oversample`（常從4試起），並微調 `size` 使字形貼近整數像素 |
| 字太大或太小     | 以 1 為單位調整 `size`                            |
| 上下偏移       | 調整 `shift` 的值                               |
| 中文風格與英文不一致 | 加入含中文的字體                                    |
| 載入慢、吃記憶體   | 降低 `oversample`                             |

### 範例

```json
{
  "providers": [
    {
      "type": "ttf",
      "file": "minecraft:Roboto-Regular.ttf",
      "shift": [0, 1],
      "size": 12.0,
      "oversample": 10.0
    }
  ]
}
```

提供者越靠前優先度越高，同一個字元只採用第一個含有它的提供者。上例的數值僅為示範，每款字體的合適值不同。

## 四、模組解法

模組會直接替換文字渲染引擎，所以能處理原版做不到的問題，同時多數仍相容原版的 JSON 字體定義。

| 模組                                              | 作法                        | 解決的問題                                                                                    | 注意                                        |
| ----------------------------------------------- | ------------------------- | ---------------------------------------------------------------------------------------- | ----------------------------------------- |
| [Modern UI](https://modrinth.com/mod/modern-ui) | 內建文字引擎，可直接使用系統字體或ttf/otf檔 | 支援 FreeType hinting、HarfBuzz text shaping、原生粗斜體、銳化字形圖集，可調字體大小、基準線位移；2D介面與3D世界文字各有對應的渲染方式 | 提供 Forge、NeoForge、Fabric 版本，Fabric版少了部分功能 |
| [Caxton](https://modrinth.com/mod/caxton)       | 以MSDF渲染文字                 | 文字在任意縮放下都能保持平滑，適合世界內文字                                                                   | 不支援hinting，低解析度螢幕上可能不如 Modern UI 銳利       |

### Modern UI 的設定重點

1. 按 Ctrl+K 開啟設定，進入字體設定。
2. 偏好字體可選系統字體，或指定TTF/OTF字體檔，並可設定備用字體。
3. 如果同時使用字體包，Modern UI的字體系列會作為原版字體的後備字體。

> 注意：(截至2026.10.31) 兩款模組的支援版本與載入器會隨時間變動，Modern UI在第三方列表上最高見到26.1.x ，並注意與其他渲染模組、光影的相容性。(模組頁面最下有寫)

---

## 五、怎麼選

只有大小、位置、缺字、效能問題時，改 `default.json` 就夠；碰到shaping、粗斜體、hinting，才需要模組。

| 你的情況             | 建議                                |
| ---------------- | --------------------------------- |
| 只是模糊或大小不對        | 原版：調整 `oversample`、`size`、`shift` |
| 缺字、中英文風格不一致      | 原版：補上含該字元的 `ttf` 提供者並排好順序         |
| 載入慢、記憶體高         | 原版：降低 `oversample`                |
| 需要阿拉伯文、泰文等複雜文字   | 模組：Modern UI 或 Caxton             |
| 想要原生粗斜體與 hinting | 模組：Modern UI                      |
| 世界內文字遠看失真        | 模組：Modern UI 或 Caxton             |
| 想直接使用系統字體        | 模組：Modern UI                      |
